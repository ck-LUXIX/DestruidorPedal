ATUALIZACAO DO REVERSE RACE 3D

Arquivos incluídos:
- index.html: página de entrada do jogo, com importmap do Three.js e carregamento de game.js como módulo.
- game.js: versão baseada em game_otimizado.js, com caminhos dos modelos 3D resolvidos a partir da localização do próprio arquivo.

COMO INSTALAR NO REPOSITORIO
1. Faça backup dos arquivos atuais.
2. Coloque index.html e game.js na mesma pasta.
3. Mantenha style.css nessa mesma pasta.
4. Dentro dessa pasta, mantenha a pasta assets.
5. Dentro de assets, mantenha os nomes exatos:
   - old_rusty_car.glb
   - teste_arvore_2.glb
6. Envie a estrutura para o GitHub e aguarde a publicação do GitHub Pages.

ESTRUTURA ESPERADA
reverse_race_project/
  index.html
  game.js
  style.css
  assets/
    old_rusty_car.glb
    teste_arvore_2.glb

OBSERVACOES
- Os nomes de pastas e arquivos diferenciam maiúsculas de minúsculas no GitHub Pages.
- Se os modelos GLB usarem texturas externas, mantenha também esses arquivos nos caminhos relativos usados pelo modelo.
- GLB normalmente pode carregar as texturas incorporadas no próprio arquivo. O GLTFLoader resolve recursos externos relativos ao arquivo GLB.
- Abra o jogo pelo GitHub Pages ou por um servidor local (por exemplo, Live Server), não apenas clicando duas vezes no HTML.
- O console do navegador (F12 > Console/Network) mostra falhas de carregamento de modelos ou texturas.
